# Тестування проекту JobRadar

## Як запускати тести
Для запуску тестів у віртуальному оточенні використовуйте команду:
```bash
python -m pytest
```

## Що покрито тестами
* **Доменний рівень (`src/jobradar/domain/`)**: Валідація бізнес-правил моделі `BudgetRow` та логіка очищення тексту.
* **Сервісний рівень (`src/jobradar/services/`)**: Валідація схем даних `BudgetIn` та перевірка конвеєра `Pipeline` на ленивість (Lazy loading).
* **Адаптери та CLI**: Логування пошкоджених рядків у файлах, коректне завершення роботи CLI з кодом 1 при відсутності файлів та перевірка пріоритетів конфігурації логування.

## Покриття коду (Coverage)
* **Початковий поріг покриття**: 56% (до оптимізації структури тестів).
* **Поточний поріг покриття**: встановлено на рівні не нижче 70% у `pyproject.toml`.

## Висновок про межі показника покриття
Метрика покриття (100% Coverage) є корисним інструментом, який наочно показує, який код **точно НЕ був виконаний** під час тестування. Проте вона абсолютно нічого не говорить про **якість самих тестів**. Тести можуть виконувати 100% коду, але при цьому пропускати логічні помилки — наприклад, неправильний пріоритет джерел конфігурації. Для надійного захисту системи необхідно комбінувати високе покриття з ретельною перевіркою бізнес-сценаріїв та крайових значень.
