# Тестування проекту JobRadar

## Як запускати тести
Для запуску тестів у віртуальному оточенні використовуйте команду:
```bash
python -m pytest
```

## Що покрито тестами
* **Доменний рівень (`src/jobradar/domain/`)**: Валідація бізнес-правил моделі `BudgetRow` (захист від порожніх значень, перевірка знаків сум, дедуплікація у множинах) та логіка очищення тексту.
* **Сервісний рівень (`src/jobradar/services/`)**: Валідація схем даних `BudgetIn` з використанням доменних функцій, робота конвеєра `Pipeline` та його перевірка на ленивість (Lazy loading).
* **Адаптери та CLI**: Логування пошкоджених рядків у файлах та коректне завершення роботи CLI з кодом 1 при відсутності файлів.
