# # Аналізатор бюджету громади

Аналізатор бюджету громади — навчальний Python-проєкт для роботи з даними порталу відкритого бюджету.

Аналізатор бюджету громади — навчальний Python-проєкт для роботи з даними порталу відкритого бюджету. Проєкт призначений для аналізу виконання видатків громади за окремими статтями бюджету та подальшого представлення отриманих даних у зручному вигляді. Основними користувачами системи можуть бути працівники органів місцевого самоврядування, аналітики, студенти та інші користувачі, які цікавляться бюджетними даними.

## Запуск проєкту

Створення віртуального середовища:

python -m venv .venv

Активація віртуального середовища у Windows PowerShell:

.venv\Scripts\Activate.ps1

Встановлення проєкту та залежностей:

pip install -e ".[dev]"

Запуск:

jobradar

Перевірка коду:

ruff check .

Форматування коду:

ruff format .

Запуск pre-commit:

pre-commit run --all-files
